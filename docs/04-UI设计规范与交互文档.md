# FlashMind — UI 设计规范与交互文档

**版本**：v1.0  
**日期**：2026-08-28

---

## 一、设计理念

### 1.1 核心风格

**「呼吸感 · 深度 · 流动」**

不追求炫技，而是让用户感到安静、专注、愉悦。灵感来自：
- Notion 的留白与克制
- Linear 的层次感和高级灰
- Duolingo 的即时反馈与情绪化交互

**关键词**：柔和阴影、圆角、微动效、高对比度文字、大留白

### 1.2 设计原则

1. **功能入口不超过 3 次点击**：任何核心操作都能快速到达
2. **复习流程零干扰**：进入复习后，屏幕只有卡片，其他全部消失
3. **情绪化反馈**：打分后有视觉/触觉反馈，让记忆行为有"完成感"
4. **移动优先**：所有触摸目标 ≥ 44px，手势优先于按钮

### 2.2 字体

```
字体族：-apple-system, 'SF Pro Display', 'PingFang SC', 'HarmonyOS Sans', sans-serif
（系统原生字体，加载零开销，渲染最自然）

字号规范：
  展示级（牌组标题、完成页数字）: 32-48px, weight 700
  标题（页面标题）               : 24px,    weight 600
  卡片内容（正面/背面）          : 20-28px, weight 500，行高 1.6
  正文（描述、说明）             : 15px,    weight 400
  辅助（标签、时间提示）         : 13px,    weight 400, color Gray-500
```

### 2.3 间距系统（基于 4px 基准）

```
4px   — 极小间距（icon 内边距）
8px   — 小间距（标签内边距）
12px  — 中小（卡片内文字 padding）
16px  — 标准（组件间距）
20px  — 中（section 间距）
24px  — 大（页面 padding）
32px  — 特大（首页模块间距）
48px  — 超大（页面顶部留白）
```

### 2.4 圆角

```
圆角-小: 8px   (按钮、输入框、标签)
圆角-中: 16px  (卡片、弹窗)
圆角-大: 24px  (牌组封面卡片)
圆角-全: 9999px (pill 形标签、进度条)
```

### 2.5 阴影

不用重阴影，用"层次感阴影"：
```css
/* 卡片阴影 - 浮起感 */
shadow-card: 0 2px 8px rgba(0,0,0,0.06), 0 0 1px rgba(0,0,0,0.04);

/* 模态框阴影 */
shadow-modal: 0 24px 48px rgba(0,0,0,0.12), 0 0 1px rgba(0,0,0,0.08);

/* 深色模式：用微亮边框代替阴影 */
border: 1px solid rgba(255,255,255,0.06);
```

## 六、动效规范

### 6.1 翻卡动画

```css
/* 容器 */
.flip-container {
  perspective: 1200px;
}

/* 内部卡片 */
.card-inner {
  transform-style: preserve-3d;
  transition: transform 0.38s cubic-bezier(0.4, 0, 0.2, 1);
}
.card-inner.flipped {
  transform: rotateY(180deg);
}

/* 正面/背面 */
.card-front { backface-visibility: hidden; }
.card-back  { backface-visibility: hidden; transform: rotateY(180deg); }
```

### 6.2 评分按钮出现动画

翻卡完成后，4个评分按钮从底部滑入：
```
delay:    0ms,  60ms, 120ms, 180ms  (交错进入)
duration: 280ms
easing:   spring(1, 80, 12, 0)     (Framer Motion spring)
from:     y: 24px, opacity: 0
to:       y: 0,    opacity: 1
```

### 6.3 打分后离场动画

用户打分后，当前卡片：
- 向对应方向飞出（忘了=左，很熟=右，模糊=下，记得=上）
- 同时下一张卡片从中心 scale(0.9) 放大进入
- 整个过程 250ms

### 6.4 页面切换

React Router 配合 Framer Motion AnimatePresence：
```
进入：x: 20px → x: 0，opacity: 0 → 1，duration: 200ms
离开：x: 0 → -10px，opacity: 1 → 0，duration: 150ms
```

### 6.5 完成页庆祝动画

- canvas 粒子撒花，持续 1.2s，共 80 个粒子
- 粒子颜色取自 Primary 色系 + 评分4色
- 主数字 count-up 动画（0 → 实际数字，duration: 800ms）

## 七、深色模式

不是简单的颜色反转，而是专门设计的暗色方案：

| 元素 | 浅色模式 | 深色模式 |
|-----|---------|---------|
| 页面背景 | `#F4F4F6` | `#0A0A0F` |
| 卡片背景 | `#FFFFFF` | `#1E1E2E` |
| 主文字 | `#111827` | `#F1F5F9` |
| 辅助文字 | `#6B7280` | `#64748B` |
| 卡片边框 | 无 | `rgba(255,255,255,0.06)` |
| 进度条底色 | `#E5E7EB` | `#2D2D3F` |

切换：跟随系统（CSS `prefers-color-scheme`），也可在设置手动覆盖。

## 八、响应式断点

```
手机端：    < 640px   (主要设计目标)
平板端：    640-1024px
桌面端：    > 1024px
```

- 手机端：单列，底部导航，紧凑间距
- 平板端：牌组改为3列网格，侧边栏替代底部导航
- 桌面端：最大宽度 480px 居中（类 iPhone 宽度），两侧留空

## 九、空状态设计

每个关键页面的空状态都需要明确引导，不能只显示空白。

| 页面 | 空状态文案 | 插图主题 | CTA 按钮 |
|-----|----------|---------|---------|
| 首页（无牌组） | 从这里开始你的记忆之旅 | 简洁线稿书本 | 创建第一个牌组 |
| 牌组详情（无卡片）| 这个牌组还没有卡片 | 空卡片堆叠 | 添加第一张卡片 |
| 今日复习完成 | 今天的卡片全部复习完了！ | 庆祝插图 | 查看统计 |
| 搜索无结果 | 没有找到「xxx」相关卡片 | 放大镜 | — |

插图风格：极简线条风，单色（Primary 色），不超过 3 个元素，文件小于 5KB (SVG)。
