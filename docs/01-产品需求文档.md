## 一、产品定位

### 1.1 一句话定义

FlashMind 是一款基于间隔重复（FSRS-5 算法）的通用闪卡学习工具，优先 Web 体验，可打包为 Android / iOS 原生 App。

### 1.2 目标用户

| 用户类型 | 场景描述 |
|---------|---------|
| 语言学习者 | 背英文单词、积累影视生词、考研词汇 |
| 备考学生 | 医学、法律、会计等需要大量记忆的科目 |
| 知识工作者 | 记录碎片知识、技术概念、专业术语 |
| 通用记忆需求 | 历史事件、公式、人名、日期等任何需要记忆的内容 |

### 1.3 核心价值主张

- **不浪费复习时间**：只在快要忘记时复习，已熟悉的跳过
- **随时随地**：PWA 离线可用，手机浏览器即开即用
- **零门槛上手**：建一张卡、翻一张卡，10秒内理解所有操作
- **数据不丢失**：本地优先存储，可选云端备份

## 三、详细功能需求

### 3.1 今日复习（Daily Review）

这是整个 App 最核心的功能，每次交互都要流畅无阻。

**流程：**

```
进入 App
  ↓
首页展示今日待复习数量
  ↓
点击「开始复习」
  ↓
显示卡片正面
  ↓
用户思考后点击「翻转」
  ↓
显示卡片背面
  ↓
用户打分：[忘了] [模糊] [记得] [很熟]
  ↓
FSRS-5 算法计算下次复习时间
  ↓
进入下一张
  ↓
全部复习完 → 显示今日完成庆祝页
```

**打分含义（对应 FSRS-5 的 rating 1-4）：**

| 按钮 | 含义 | FSRS Rating | 视觉颜色 |
|-----|------|------------|---------|
| 忘了 | 完全不记得 | 1 | 红色 |
| 模糊 | 想起来了但很吃力 | 2 | 橙色 |
| 记得 | 正常记起 | 3 | 蓝色 |
| 很熟 | 轻松记起 | 4 | 绿色 |

**关键细节：**
- 打分按钮下方显示预计下次复习时间（"3天后" / "12天后"），让用户直观理解分数的影响
- 支持手势：左滑=忘了，右滑=很熟（移动端）
- 支持键盘快捷键：1234 对应四个评分，空格键翻卡
- 复习进度条显示在顶部（已完成/总数）
- 支持「撤销上一张」按钮，防止误操作

### 3.2 牌组管理（Deck Management）

**牌组属性：**
- 名称（必填，最长 50 字）
- 描述（选填）
- 封面颜色（从 12 个预设色中选，或自定义）
- 图标 emoji（选填）
- 创建时间
- 状态：活跃 / 归档

**牌组首页卡片展示：**
- 牌组名 + emoji + 颜色
- 今日到期数量（红点提示）
- 总卡片数
- 掌握进度条

**操作：**
- 长按牌组：快捷菜单（编辑/归档/删除）
- 删除牌组前必须二次确认，明确告知「该牌组下 X 张卡片将被永久删除」

### 3.3 卡片管理（Card Editor）

**卡片正面/背面支持内容类型：**
- 纯文本（默认）
- Markdown（支持加粗、斜体、代码块）
- 图片（本地上传，压缩后存 IndexedDB）
- 混合（文字+图片）

**批量导入（CSV 格式）：**
```csv
front,back
apple,苹果
banana,香蕉
```

第一行为表头，front 是正面，back 是背面，自动归入当前牌组。

**搜索：**
- 在卡片列表内实时搜索
- 搜索范围：正面文字 + 背面文字
- 高亮匹配字符

### 3.4 统计中心（Stats）

**今日概览（首页即可见）：**
- 今日已复习 / 今日待复习
- 当前连续打卡天数（🔥 N天）
- 今日新学卡片数

**详细统计页：**
- 过去 30 天每日复习量柱状图
- 记忆保留率折线图（理论遗忘曲线对比实际表现）
- 各牌组卡片掌握分布（新建/学习中/已掌握/过期）

### 3.5 设置（Settings）

| 设置项 | 默认值 | 说明 |
|-------|-------|------|
| 每日复习上限 | 200 张 | 防止单日堆积过多 |
| 每日新卡上限 | 20 张 | 控制学习速度 |
| 学习提醒 | 关闭 | 设置时间后推送通知（PWA/App） |
| 复习顺序 | 随机 | 可选：按到期时间升序 |
| 自动播放音频 | 关闭 | 卡片翻转后自动播放背面音频 |
| 数据导出 | — | 导出为 JSON 文件（含所有卡片和学习记录） |
| 数据导入 | — | 从 JSON 恢复，支持合并或覆盖 |

## 四、用户旅程地图

### 4.1 新用户首次使用

```
首次打开
  → 空状态引导页（简洁插图 + "创建第一个牌组"按钮）
  → 输入牌组名称（如"英语词汇"）
  → 进入牌组，空状态 + "添加第一张卡片"
  → 添加几张卡片
  → 点击「开始复习」
  → 第一次完成复习 → 庆祝动画 + 提示明日复习时间
```

### 4.2 日常使用（留存场景）

```
打开 App
  → 首页直接看到「今日待复习 N 张」
  → 一键开始
  → 快速过完，获得成就感
  → 关闭
```

### 4.3 添加卡片（内容生产场景）

```
看到生词
  → 打开 App
  → 进入对应牌组（或快捷添加不选牌组，归入默认）
  → 输入正面（生词）/ 背面（释义）
  → 保存，2秒完成
```

## 五、非功能性需求

### 5.1 性能指标

| 指标 | 目标 |
|-----|------|
| 首屏加载时间 | < 1.5s（冷启动） |
| 翻卡动画帧率 | 60fps |
| 打分响应时间 | < 100ms |
| 搜索响应时间 | < 200ms（1万张卡片内） |
| IndexedDB 写入 | < 50ms / 次 |

### 5.2 离线能力

- 核心复习功能完全离线可用
- 数据100%本地存储（IndexedDB）
- PWA Service Worker 缓存所有静态资源
- 网络恢复后自动同步（如启用云端备份）

### 5.3 安全性

- 数据仅存本地，不上传任何内容到第三方
- 图片存储前压缩，防止 IndexedDB 超限
- 导出文件不含任何敏感元数据
- 云端同步（可选）使用 JWT + HTTPS

### 5.4 可访问性

- 所有交互元素有 aria-label
- 支持键盘完整操作
- 颜色方案满足 WCAG AA 对比度标准
- 支持系统深色模式

## 六、产品边界（不做的事）

| 功能 | 不做的原因 |
|-----|----------|
| AI 自动生成卡片 | V1 保持简单，后续迭代 |
| 多用户协作共享牌组 | 复杂度高，V1 个人使用 |
| 音频录制 | V1 不做，可从本地导入音频文件替代 |
| 视频内容嵌入 | 存储成本高，不在核心场景内 |
| 社交排行榜 | 非核心价值 |
